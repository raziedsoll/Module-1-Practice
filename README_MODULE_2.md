# Модуль 2. Практика. Задание 1.

## Классы и логика работы

- `Module2PracticeApplication` запускает Spring Boot с профилем `moderation`.
- `Message` содержит отправителя (`from`), получателя (`to`) и текст (`text`).
- `ModerationTopology` читает сообщения из `messages` и применяет правила из двух `GlobalKTable`. Таблицы хранятся в RocksDB и обновляются при поступлении новых правил.

Если отправитель входит в список блокировок получателя в `blocked_users`, приложение отбрасывает сообщение. В остальных сообщениях оно заменяет целые слова из `banned_words` на `***` без учёта регистра и записывает результат в `filtered_messages` с ключом `to`.

## 1. Запусти кластер

```bash
docker compose -f compose.moderation.yaml up -d --build
```

Дождись `RUNNING`. Открой [Kafka UI](http://localhost:8080) → **moderation → Topics**.
